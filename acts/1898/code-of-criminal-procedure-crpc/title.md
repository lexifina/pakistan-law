# THE CODE OF CRIMINAL PROCEDURE, 1898
THE CODE OF CRIMINAL PROCEDURE, 1898
[^1]ACT NO. V OF 1898
[22nd March, 1898]
An Act to consolidate and amend the law relating to the Criminal Procedure.
WHEREAS it is expedient to consolidate and amend the law relating to Criminal Procedure; It is hereby enacted as follows:__
